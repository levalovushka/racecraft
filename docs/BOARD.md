# Доска менеджера (концепция)

Живой экран на планшете для менеджера одного пилота. Термины — в [GLOSSARY.md](GLOSSARY.md), механика — в [MECHANICS.md](MECHANICS.md).

## Принципы
1. **Считать до события, узнавать во время события.** Под стрессом рабочая память и сравнение вариантов работают плохо, а заученные реакции — хорошо. Доска заранее превращает расчёт в готовую фразу.
2. **Только факты и их механические следствия.** Бокс, фазы, стинты, классы, кто куда попадёт по правилу входа. Без моделей личностей соперников и без их истории.
3. **Решает менеджер.** Пилот ничего не проверяет и не высматривает, только выполняет команды.
4. **Базовый прогноз исходит из того, что соперники действуют эффективно.** Отдельно доска готовит реакцию на их ошибки (позиция запасного).
5. **Цикл решения — один круг**, между двумя проездами нашего пилота мимо въезда.

## Экран (три зоны)
```
┌───────────────────────────────────────────────────┐
│ КРУГ 11/60  P10  Карт 8 [B]  Стинт 11 (мин ✓)      │ 1. МЫ
│ До пересида 29 · Свобода 30 · Питы 0/2             │
├───────────────────────────────────────────────────┤
│ БОКС  3[C] | 12[A]    КРАСНЫЙ ещё 14 с             │ 2. РЕШЕНИЕ
│ 12[A] → претендент #7 (твёрдый) · мы запасной +7 с │
│ СМОТРИ: #7 у въезда через 11 с   ОКНО 3 с ✓        │
│ Проедет мимо → «Бокс, бокс»   Въедет → «Остаёмся»  │
│ СЕЙЧАС → 3[C] ✗ · кругов на нём 39                 │
├───────────────────────────────────────────────────┤
│ У ВЪЕЗДА после зелёного:                           │ 3. ОЧЕРЕДЬ
│  +3с #7 7[C] голодный ✓хочет 12                    │
│  +7с МЫ                                            │
│ +12с #3 4[C] голодный ✓хочет 12                    │
│ (сытые и вне игры свёрнуты)                        │
└───────────────────────────────────────────────────┘
```

## Главная строка
**карт → претендент (твёрдый / мягкий) → запасной → куда смотреть → заготовка**
- Если **мы претендент**: «Бокс».
- Если **мы запасной и окно реакции > 0**: доска говорит, кого и когда смотреть, и даёт две готовые фразы.
- Если **мы запасной, но окна нет**: «нет времени», реакция на это событие невозможна.
- Если **мы третьи и дальше**: строка приглушена.

## Режимы доски
| Режим | Когда | Что крупно |
|---|---|---|
| Спокойный | Бокс мёртвый, все сытые | До пересида, темп, трафик |
| Волна | Бокс живой, идёт конвейер | Очередь: место → кто → какой карт |
| Дедлайн | Запас до пересида ≤ числу горящих перед нами | Красная плашка «окно закрывается» |
| Атака | Переключатель риска (см. [EDGES.md](EDGES.md)) | Покупка под красным, скрытый класс, окна без конкуренции |

## Что доска считает сама
- Состояние бокса, лента, сколько осталось красного. Источник — `pitlaneKarts` и история питов.
- Фазы и порядок, в котором пилоты проедут въезд после зелёного.
- Стинты, «до пересида», свобода, стадия голода каждого пилота.
- Претендент и запасной для первого и второго карта в боксе — по правилу входа.
- Окно реакции.
- «Кругов на нём» и ценность каждого варианта пита.
- Где мы выедем после пита: за кем окажемся и на каком расстоянии (см. [EDGES.md](EDGES.md)).
- Живая переоценка классов картов по кругам с поправкой на пилота (см. [EDGES.md](EDGES.md)).

## Что вводит менеджер
- Классы картов перед гонкой и поправки по ходу.
- Брифинг: число кругов, M.
- Замеры трека: от линии отсечки до точки решения и до въезда.
- Касанием по ходу гонки: «этот не поедет / поедет», «режим атаки».

## Связь
«Готовность» → «Бокс, бокс» / «Остаёмся» / «Отбой». Подробности в словаре.

## Отклонённые идеи (и почему)
- **Профили пилотов по истории** — новые люди, менеджеры меняются, на гонках бывает разная техника.
- **Аукцион и бюджеты ожидания как основа решений** — под красный никто не встаёт. Бюджет остаётся только в режиме атаки.
- **Условия, которые проверяет пилот** — у пилота другая задача, а светофор бокса он видит не на всех треках.

## Что нужно до первой версии
1. Проверить WebSocket во время живого заезда: формат сообщений, частоту, задержку относительно реальности.
2. Замерить на каждом треке точку решения и въезд.
3. Сделать режим повтора по истории питов прошлых гонок — для отладки и тренировки менеджера.
