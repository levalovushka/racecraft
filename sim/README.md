# racecraft · симулятор менеджера

Веб-тренажёр: полная гонка «Гонщик года» на Премиуме в реальном времени, вы командуете своим пилотом, после финиша — разбор против бота на той же раздаче. Спецификация — [../docs/SIMULATOR.md](../docs/SIMULATOR.md).

```
npm install
npm run dev        # http://localhost:5173
npm run validate   # 300 гонок без интерфейса против данных Премиума (нужен ../data/races.json)
npm run typecheck
npm run build
```

## Устройство
- `src/engine/` — движок без React: `race.ts` (гонка, бокс, светофор, стинты, трафик), `ai.ts` (правило входа для соперников и бота), `analysis.ts` (бот-эталон, оценка решений Монте-Карло), `track.ts` (трасса из `../tracks/premium-std.json`), `rng.ts` (детерминированный шум по ключам).
- `src/sim/` — то, что считает доска менеджера: прогноз питов соперников (конвейер бокса), исход каждого указания, точка выезда, статусы соперников, виртуальная позиция; цикл анимации; воркер для оценки решений.
- `src/components/` — экраны: настройка, гонка, разбор (shadcn/ui).
- `scripts/validate.ts` — сверка поведения поля с данными.

## Управление
Указание пилоту действует до отмены и передаётся на точке решения перед линией: `S` — мимо, `C` — бокс, если перед ним никто не въедет в пит-лейн (пилот решает сам у въезда), `B` — бокс. Пробел — пауза, `1–5` — скорость 1×–16×. Клик по карту в тайминге или на трассе (в том числе в боксе) меняет вашу оценку класса. Интерфейс на английском и русском, переключатель у лого. Устройство интерфейса — [../docs/UX.md](../docs/UX.md).

На старте можно задать фамилию и свой старт: позицию на решётке и класс стартового карта. Остальное определяет раздача, бот на разборе стартует так же.
